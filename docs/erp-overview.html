4 · Buy materials → pay suppliers

Procurement · Warehouse · Payables · VAT

Site asks for material, the office gets competing quotes, the winner gets a PO, the store receives it, and the material is issued to the project where it becomes cost. The supplier's bill flows to payables and its VAT becomes recoverable input tax.

5 · Payment certificate (IPC) maths

Worked example: IPC-2401-09, Al Wathba Industrial Access Road

Where cumulative work comes from

Earned value = Σ (BOQ done qty × sell rate)
Cumulative work = Earned value + approved VOs × % complete
  • Site staff update done quantity per BOQ line.
  • Approved variation orders are added pro-rata to progress.
  • “New IPC from progress” takes this figure automatically.

Deductions (set in Settings)

Retention = 10% × work this period
Advance recovery = 10% × work this period
Net = work − retention − advance recovery
VAT = 5% × net · Total due = net + VAT
  • Retention is tracked as money held by the client and released at handover / end of defects liability.

Status path

  • Draft → Submitted to the engineer → Certified (a tax invoice is issued automatically) → Paid when the receipt clears the invoice.

Revenue recognition (Finance)

% complete = cost to date ÷ estimated total cost
Revenue to date = revised contract × % complete
Contract asset / (liability) = revenue − certified

8 · Accounting & group companies

Every transaction posts itself to the ledger

Nobody keys journals for day-to-day work: invoices, receipts, bills, payroll, stock issues, depreciation and plant hire each create a balanced double entry. Two companies keep separate books — Jazallah Road Contracting and Jazallah Plant Hire (which owns the fleet and hires it to JRC) — and the group view removes the internal hire.

10 · Under the hood

Current demo version

How it runs

  • Plain HTML, CSS and JavaScript — no installation, no server, no build step.
  • Open erp/index.html in any modern browser.
  • Each screen is a page module; the address bar hash (e.g. #/projects/P-2401/chainage) decides which one shows.
  • The Site app can be installed on a phone's home screen when the ERP is served over the web.

Where the data lives

  • First launch loads the sample company from data.js.
  • Every change is saved in the browser's local storage, so it survives a refresh.
  • Settings → Export backup downloads everything as one JSON file; Import restores it; Reset returns to the sample.

Limits of the demo

  • Users are switched from a menu, not real logins; roles limit what each person sees but are not enforced by a server.
  • E-invoices are generated as XML files; email opens your mail app.
  • Data is per browser; colleagues don't see each other's changes.

Path to production

  • Move the data store to a hosted database (e.g. Supabase) with user accounts and role-based access.
  • Keep the same screens and calculations — only the store layer changes.
  • Add email notifications, a mobile layout for site staff and document attachments.
